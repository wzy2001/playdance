## 产品定位

本地优先的视频播放器，核心是**辅助跳舞练习**：把任意视频用「分割点」切成若干连续段，选中若干连续段作为「块」，整块循环播放；并能分块录制配音，之后把配音与原视频同步叠加播放。

## 需求维度（对应 DESIGN.md 章节）

| 维度 | DESIGN.md 节 | 要点 |
|------|--------------|------|
| 视频来源 | 2.1 | 本地导入 + 网络 URL 元信息/下载；全部存 App 私有目录 |
| 主页（视频库） | 2.2 | 列表项：标题/封面/时长/是否有配音；悬浮「+」按钮 |
| 播放器页 | 2.3 | 播放/分段/配音/循环合并到一个界面，共享时间轴状态 |
| 分段与循环 | 2.4 | N+1 段；分割点可增删/毫秒微调；连续段成块；整块无限循环 |
| 配音录制 | 2.5 | 以块为单位；@1x 录制；手动停止取实际时长靠前对齐，剩余静音；一视频一拼接音轨 |
| 回放 | 2.6 | 原声/配音双音轨独立调音量 + 配音开关；倍速 0.5–1.0 对整体生效 |
| 手势 | 2.7 | 长按右=0.5x / 长按左=2x 模拟倒放 / 横滑快进快退；录制态屏蔽 |
| 全屏与控件显隐 | 2.8 | 默认真沉浸全屏；单击唤出控件；单击中间或超时隐藏；屏幕常亮 |
| 横竖屏 | 2.9 | 都适配；FIT 缩放留黑边；方向跟随设备，不锁死不自动旋转 |

## 关键既决决策

见 DESIGN.md 第 6 节「关键边界与已定决策」共 17 项（录音原声照常播、配音随块循环、块粒度、倍速范围、仅无限循环、分割点可米级微调、网络视频参与分段配音、合并播放器页、录音锁定 1x、手动停止靠前对齐、独立音量+开关、四种手势、沉浸全屏、横竖屏 FIT、倒放为模拟实现、控件 3 秒超时）。

## 非目标（本期不做）

- 循环 N 次（仅无限循环）
- 真实逐帧倒放（用模拟倒放替代，已确认）
- 倍速 > 1.0（0.5–1.0 范围，架构预留但本期不做）
- 配音文件物理拼接（仅播放时按时间组合音源，概念上一整轨）
- 转码 / 视频编辑
